# 详情页转化率审核

> 一个页面卖不动，先别改设计，先查转化链断在哪一节。

诊断商品详情页、落地页、营销页为什么没把流量转成订单、线索、咨询或预约，然后给出最小可执行的改动路径。

不是审美点评。审美管"这东西看起来值不值这个价"，这个技能管"用户为什么走到一半就走了"。

---

## 它解决什么问题

页面有流量、有曝光，就是不下单。你去问人，得到的答案通常是"设计不够好看""文案不够吸引人"——这两句话都没法执行。

这个技能干的是另一件事：**把"卖不动"拆成七个可以单独检查的环节**，指出到底断在哪一环，以及改哪一处最省事、见效最快。

```
流量意图 → 首屏留存 → 卖点选择 → 信任建立 → 行动动机 → CTA 执行 → 异议处理
```

断在前三环，改视觉没用。断在后两环，改结构没用。

---

## 三种用法

| 模式 | 你要什么 | 它给什么 |
| :-- | :-- | :-- |
| **快速体检** | 想知道大概哪里有问题 | 5-8 个最要紧的问题 + 最快能改的几处 |
| **深度诊断** | 要一份能拿去开会的东西 | 逐模块诊断报告 + 优先级 + 改动成本 + 置信度 |
| **直接改版** | 别说了，给我能用的 | 首屏结构、卖点排序、按钮文案、模块顺序的具体替换方案 |

---

## 输出长什么样

固定六段，从判断到行动：

1. **一句话结论** —— 这页最致命的问题是什么
2. **问题清单表** —— 按 P0/P1/P2/P3 分级，标影响程度、修改成本、判断置信度
3. **逐模块诊断** —— 每个模块：现在什么样 → 违反了哪条规则 → 影响什么 → 怎么改
4. **改版方案** —— 先改快的，再改结构
5. **A/B 测试建议** —— 哪些判断没数据支撑，必须先测
6. **缺什么数据** —— 明确标出哪些是假设

P0 = 挡住下单或制造强烈不信任；P3 = 打磨项或待测项。**没有数据的判断一律标为"待验证假设"，不装作确定。**

---

## 能查什么

- 首屏：标题、四个卖点、CTA、背景、LOGO 位置
- 卖点：通用卖点 / 独有卖点 / 保障卖点，数量上限（首屏 ≤4，全页 ≤8），排序
- 页面结构：消除疑虑 → 方案优势 → 限时限量 → 答疑
- 图片视频：每张图是否在表达卖点、颜色数量、字幕层级、BGM 音量
- 文案：F→B 而不是 FAB、标题=核心卖点+凭证、数字要具体
- 按钮：Fogg 模型（动机×能力×提示）、文案前后缀、位置
- 排版：一模块说一件事、F 型视线、标注线
- 渠道匹配：**不是所有转化问题都是页面问题**

最后这条最容易被忽略。页面本身没毛病，但进来的流量意图不对，改页面是白改。技能会先分清是页面问题还是流量问题。

## 安装

把整个目录放进你的 skills 目录：

```bash
# Codex
~/.codex/skills/detail-page-conversion-audit

# Claude Code / 通用 Agent Skill
~/.agents/skills/detail-page-conversion-audit
```

目录里必须保留 `SKILL.md` 和 `references/`。

---

## 使用

给它页面截图、长图、URL、PDF 或 HTML，说清楚你要哪种模式：

```text
用 detail-page-conversion-audit 诊断这个商品详情页，
找出影响转化的问题，给出优先级、改法和 A/B 测试建议。
```

补充这些信息，诊断会准很多：

- 商品类目和价格
- 目标用户
- 流量来源（搜索 / 信息流 / KOL / 私域 / 货架 / 投放）
- 当前转化目标（下单 / 留资 / 咨询 / 预约）
- 现有数据：曝光、点击率、首屏跳出、加购率、支付转化率、ROI
- 竞品页面

**没有数据也能跑**，但技能会明确标出哪些是推断。

## 和「审美质感」的分工

昊哥的开源技能里有两个容易混的：

| 技能 | 管什么 | 判断什么 |
| :-- | :-- | :-- |
| **详情页转化率审核**（本仓库） | 结构 → 行动 | 用户为什么不往下走 |
| [**昊哥-审美质感**](https://github.com/gxh98/haoge-aesthetic-quality) | 质感 → 信任 | 这东西看起来值不值这个价 |

一个页面卖不动，可能是"看不懂"（结构问题），也可能是"不信"（质感问题）。先分清是哪一种，再决定改哪个。
