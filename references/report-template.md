## Short Audit Format

For quick audits, use:

```markdown
一句话：...

最该先改的 5 个点：
1. [P1] 位置：问题 -> 改法
2. [P1] 位置：问题 -> 改法
3. [P2] 位置：问题 -> 改法
4. [P2] 位置：问题 -> 改法
5. [P3] 位置：问题 -> 改法

建议先做的 A/B 测试：
- ...

我还需要的数据：
- ...
```
