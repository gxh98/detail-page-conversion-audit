# Iteration Playbook

Use this file to convert diagnosis into concrete changes.

## Common Problems and Fixes

| Problem | Likely Impact | Fix |
|---|---|---|
| First screen only says product name or category | Users do not know why to stay | Add core selling point + credential headline, 4 concise selling points, and CTA |
| Too many selling points in first screen | Attention disperses | Keep 4 points; prioritize unique, then generic, then assurance |
| Only product attributes are shown | Users do not see personal benefit | Rewrite with FB: attribute + consumer benefit |
| No assurance selling point | Users worry about risk | Add warranty, refund, genuine, safety, no hidden fee, no side effect, after-sales policy, or category-specific risk removal |
| Offer appears before trust | Looks pushy or cheap | Move proof and solution before limited offer |
| Button says only "了解更多" or "免费预约" | Weak action motivation | Use instruction + motivation: "现在咨询 获取本地报价" |
| Button visually blends into background | Users miss the action | Increase contrast, use solid button, enlarge clickable area |
| Image is beautiful but not meaningful | Visual attention does not convert | Replace with image that directly demonstrates the selling point |
| Decorative props distract | Selling point becomes unclear | Remove props, colors, icons, and people that do not support the point |
| One module says several things | Users cannot grasp the logic | Split into one module per selling point |
| Proof is too small or buried | Trust is not built | Enlarge proof, place it near the claim, use labels/callouts |
| Technical parameter has no translation | Users cannot understand value | Add consumer meaning: "视野更宽阔", "刷剧 4 小时", "护颈又减压" |
| Embedded video slows the page | Users leave before seeing content | Remove unless video uniquely demonstrates the selling point |
| Traffic promise and page first screen mismatch | High bounce | Rewrite first screen to echo keyword/ad/KOL promise |

## First-Screen Rewrite Formula

Use this structure:

- Product/brand identifier
- Main headline = core selling point + credential
- 4 concise selling points = 2 unique + 1 generic + 1 assurance
- Hero image = product or scene that directly demonstrates the main selling point
- CTA = action instruction + motivation

Example shape:

```text
[品牌] · [产品名]
[核心卖点]，[信任状]
[独特卖点1]  [独特卖点2]  [通用卖点]  [保障卖点]
[产品/场景图]
[现在咨询 获取本地方案]
```

## Copy Rewrite Formula

Turn F/FA into FB:

- F-only: "霍尔线性扳机"
- FA: "霍尔线性扳机，品质更高"
- FB: "霍尔线性扳机，操控更顺手"

Use this pattern:

```text
[可信属性/证据] + [用户得到的好处]
```

Good benefit words are concrete:

- 更省心
- 更安全
- 更好喝
- 更轻松
- 不累脚
- 不留痕
- 不额外收费
- 不联网也能用
- 充电 5 分钟，刷剧 4 小时

Avoid:

- Empty adjectives: 高端、优秀、卓越、匠心 unless backed by proof
- Internal jargon without translation
- Metaphors that require interpretation
- Apologetic phrasing

## CTA Rewrite Formula

CTA = instruction + motivation.

Examples:

- 现在下单 领取限时赠品
- 点击查看 适合你的套餐
- 现在咨询 获取本地报价
- 立即预约 查看附近门店
- 免费领取 门店增长方案
- 现在测评 找到脱发原因

Match CTA to the module:

- Store density module -> nearby store address
- Price/value module -> local quote or package price
- Effect module -> before/after result or assessment
- B2B solution module -> solution, ROI, demo, diagnostic report
- Limited offer module -> coupon, gift, installment, free shipping

## Module Order Fixes

Default sequence:

1. Remove doubt
2. Solution + advantages
3. Limited offer
4. Warm reminder + Q&A

When to adapt:

- Low price/impulse purchase: CTA can appear earlier and more often.
- High price/high risk: add more proof, cases, warranty, qualification, and Q&A before hard CTA.
- B2B: emphasize diagnosis, ROI, process reliability, implementation proof, and case outcomes.
- New category: explain use scene and problem before product details.
- Known search demand: echo the search keyword immediately.

## A/B Test Menu

Test high-impact hypotheses first.

| Test | Version A | Version B | Metric |
|---|---|---|---|
| Headline | Current headline | Core selling point + credential | First-screen drop-off, scroll depth |
| Selling-point mix | Current points | 2 unique + 1 generic + 1 assurance | CTA click, add-to-cart |
| CTA copy | Generic CTA | Instruction + motivation CTA | CTA click |
| Hero image | Product beauty shot | Selling-point demonstration shot | First-screen retention |
| Module order | Current order | Remove doubt -> solution -> offer -> Q&A | Conversion rate |
| Proof display | Proof buried | Proof near claim with enlarged visual | Scroll depth, add-to-cart |
| Offer | Discount only | Gift/discount tied to product use | Purchase rate |
| Q&A | No Q&A/simple FAQ | Ordinary + professional Q&A | Consultation rate, customer-service load |

## Data to Request When Available

- Top traffic source and user intent
- Main keyword or ad/KOL promise
- First-screen bounce or drop-off
- Scroll depth by module
- CTA click rate by position
- Add-to-cart and payment rate
- Customer-service questions
- Refund/complaint reasons
- Competitor pages and price differences
